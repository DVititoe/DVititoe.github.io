\doxysubsection{Detailed Description}
Abstract class that provides basic button functionality. 

This is the base class for all buttons. This class manages the button states and provides methods for pressing, releasing, enabling, and disabling the button. Derived classes will define how many states the button has and will provide the \doxylink{class_button_state}{Button\+State} objects that define the appearance and functionality of each state.
